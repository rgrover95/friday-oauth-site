RajOS connects to Google Drive with the account owner’s authorization to retrieve personal documents for search and contextual assistance. A separate authorized writing integration supports approved record updates. Primary chat and search processing run locally; authorized external assistants and encrypted cloud backups are described in the privacy policy.
